# Vocabulário de triage

O repositório tem as labels padrão do GitHub. A entrega E01 está descrita nas Issues #1 e #2 sem exigir novas labels.

Vocabulário convencional para necessidades futuras de triage:

| Termo | Significado | Situação no GitHub em 06/09/2026 |
| --- | --- | --- |
| `needs-triage` | Demanda recebida, ainda sem classificação. | Não criado. |
| `needs-info` | Falta informação necessária para avançar. | Não criado. |
| `ready-for-agent` | Demanda com escopo e aceite suficientes para execução. | Não criado. |
| `ready-for-human` | Demanda que depende de uma decisão humana específica. | Não criado. |
| `wontfix` | Demanda explicitamente descartada. | Label existente. |

Os estados desta entrega (`todo`, `in_progress`, `done`) são registrados no corpo das Issues e resumidos no roadmap; não representam labels já aplicadas.
